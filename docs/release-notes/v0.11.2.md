# v0.11.2

Bugfix. Non-breaking; no CRD/API change.

## Fixed

- Turning nodepool autoscaling on or off (and editing `minSize`/`maxSize`) on
  a live pool had no effect — the settings only applied at creation. They now
  converge day-2.
- Lowering `nodeCount` together with disabling autoscaling caused an endless
  scale fight with the still-enabled upstream autoscaler. The flag is now
  disabled first, and the controller never scales while autoscaling is
  observed enabled.

See [docs/kubernetes.md](https://github.com/lebedevdsl/crossplane-provider-timeweb/blob/v0.11.2/docs/kubernetes.md).
